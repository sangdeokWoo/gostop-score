# 🃏 고스톱 점수계산기

가족과 함께 즐기는 모바일 고스톱 점수 계산기

**👉 [바로 사용하기](https://sangdeokwoo.github.io/gostop-score/)**

---

## 주요 기능

- **3~4명** 지원 — 플레이어 이름 직접 입력
- **기본 단위(판돈)** 직접 설정
- **판마다 점수 입력** → 누적 잔액 자동 계산
- **특수 규칙** 전부 지원: 고/스톱 배율, 흔들기, 폭탄, 피박, 광박
- **최종 정산** — 누가 누구에게 얼마 줘야 하는지 명확하게
- **카카오톡 공유** — 결과 텍스트 한 번에 공유
- **자동 저장** — 새로고침해도 게임 유지

## 규칙

| 항목 | 계산 |
|------|------|
| 점수 | 3점=1단위, N점=(N-2)단위 |
| 고 | N번 고 → 전체 ×(N+1)배 |
| 흔들기 | 전체 ×2배 |
| 폭탄 | 전체 ×2배 |
| 피박 | 해당 패자만 ×2배 |
| 광박 | 해당 패자만 ×2배 |
