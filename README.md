#  고스톱 점수계산기

모바일 최적화 고스톱 점수 자동 계산기 — 판마다 결과를 입력하면 누적 잔액과 최종 정산까지 자동으로 처리합니다.

**👉 [바로 사용하기](https://sangdeokwoo.github.io/gostop-score/)**

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 👥 인원 선택 | 2~6명 지원, 플레이어 이름 직접 입력 |
| 💰 판돈 설정 | 기본 단위(원) 직접 입력 |
| 🀄 판 입력 | 승자·점수·고 횟수·특수 규칙 입력 → 자동 계산 |
| 📊 누적 잔액 | 판마다 실시간 업데이트 |
| 🏆 최종 정산 | 최소 이체 횟수로 누가 누구에게 얼마 줄지 계산 |
| 📤 공유 | 결과 텍스트 카카오톡 등으로 바로 공유 |
| 💾 자동 저장 | localStorage — 새로고침/앱 재실행 시 게임 복원 |
| ❓ 도움말 | 규칙·사용법 바텀시트 모달 |

---

## 고스톱 규칙

| 항목 | 계산 방식 |
|------|-----------|
| 점수 기본 | 3점 = 1단위, N점 = (N-2)단위 |
| 고(GO) | N번 고 선언 후 스톱 → 전체 ×(N+1)배 |
| 흔들기 | 같은 달 카드 2장 보유 시 선언 → 전체 ×2배 |
| 폭탄 | 같은 달 카드 4장 보유 시 선언 → 전체 ×2배 |
| 피박 | 피 5장 미만인 패자 → 해당 패자만 추가 ×2배 |
| 광박 | 광이 없는 패자 → 해당 패자만 추가 ×2배 |
| 정산 | 패자들이 각자 승자에게 지급 (2~6인 모두 동일 방식) |

> 흔들기+폭탄 중첩 가능 (×2 × ×2 = ×4배)

## 기술 스택

- **순수 HTML/CSS/JS** — 프레임워크 없음, 단일 파일(`index.html`)
- **GitHub Pages** 배포 — `main` 브랜치 직접 서빙
- **Google Fonts** — Noto Sans KR
- **Web Share API** — 카카오톡·메시지 앱 공유, 미지원 시 클립보드 복사로 폴백
- **localStorage** — 게임 상태 자동 저장/복원

## 개발 이력

### v1 — 초기 구현
- 3~4인 고스톱 점수 계산 기본 기능
- 고/스톱 배율, 피박·광박·흔들기·폭탄 규칙 적용
- 판 기록, 누적 잔액, 최종 정산 화면
- localStorage 자동 저장
- 판 입력 취소(Undo) 기능

### v2 — UI/UX 개선
- 다크 테마 전면 적용 (검은 배경, 네온 그린 포인트)
- 모바일 최적화 레이아웃 (max-width 430px)
- 유리 모폼 카드(Glassmorphism) 스타일
- 히어로 아이콘 → 광카드(光) SVG 직접 제작
  - 빨강 카드 외곽 + 흰 달 + 검은 언덕 곡선 + 光 뱃지
  - 라디알 그라디언트, 드롭섀도, 광택 레이어로 이모티콘 느낌
- 폰트 Noto Sans KR 적용

### v3 — 기능 고도화
- **카카오톡 공유 OG 태그** 추가
  - `og:title`, `og:description`, `og:url`, `og:image` 완비
  - `og-image.svg` (1200×630) 별도 제작
- **도움말 바텀시트 모달** 추가
  - 앱 사용법 5단계
  - 기본 점수 계산, 고/스톱 배율, 특수 규칙, 정산 방식 섹션별 정리
  - 우측 상단 `?` 버튼, 바깥 탭 시 닫힘
- **판 추가 FAB** 라벨 표기 (`+` → `+ 판 추가`)

### v4 — 버그 수정 및 안정화

#### 버그 수정
| 항목 | 내용 |
|------|------|
| 폭탄 배율 표기 오류 | 도움말에 ×4배로 잘못 표기 → 실제 계산(×2배)에 맞게 수정 |
| 점수 뱃지 오표시 | `(score-2)단위` 계산 시 `Math.max(1, score-2)` 적용, 0단위 방지 |
| SVG 그라디언트 ID 충돌 | 페이지 내 동일 ID 충돌 → `hiCardBg`, `hiSkyBg` 등 고유 ID로 변경 |
| 光 뱃지 테두리 잘림 | 카드 외곽 stroke가 뱃지 위에 렌더링 → 드로우 순서 수정 |
| 빈 화면 텍스트 미반영 | 정적 HTML 수정됐으나 JS `renderHistory()` innerHTML은 별도 존재 → 동기화 |

#### 오류 처리 강화
| 항목 | 내용 |
|------|------|
| 클립보드 복사 실패 | `navigator.clipboard` 실패 시 `.catch()` 추가 → `execCommand` 폴백 |
| 폴백도 실패 시 | try/catch로 감싸 사용자에게 안내 메시지 표시 |
| 모달 배경 스크롤 | `openModal()` 시 `body overflow:hidden` 처리, `closeModal()` 시 복원 |
| localStorage 불가 환경 | `save()`/`load()` 전체 try/catch로 감싸 — 시크릿 모드 등 대응 |
| 이름 중복 입력 | Set 비교로 감지, 게임 시작 차단 및 안내 |

### v5 — 2~6인 확장 및 추가 수정
- **인원 수 2~6명으로 확장** (기존 3~4명)
  - 인원 선택 버튼 5개 (2·3·4·5·6) flex 레이아웃
  - 플레이어 색상 6가지 (`av0`~`av5`) 추가 정의
  - 메달 배열 6개 (`🥇🥈🥉🏅🏅😢`)
  - 2인 게임 포디움 표시 별도 처리
  - CSS 포디움 바 `.p5`, `.p6` 클래스 추가
  - 도움말 "2~6인 게임" 통합 안내로 업데이트
- **기본 이름 플레이스홀더** 6개로 확장 (플레이어1~6)
- **meta description** 2~6인 지원으로 수정

## 배포 방법

GitHub Pages — `main` 브랜치의 루트를 바로 서빙합니다.

```
Settings → Pages → Source: Deploy from branch → main / / (root)
```

별도 빌드 과정 없음. `index.html` 수정 후 `main`에 push하면 자동 반영됩니다.
